# CMDB 原型 UI 对齐记录

2026-11-03，按用户指定的 Ant Design Pro 参考和 MamreTek 中央规范 1.3 第 3.1 节调整当前原型。沿用现有 React、TypeScript、Ant Design 及 API/Mock 分层，没有引入新的框架或业务依赖。

## 实际参考范围

- 用户指定的 https://preview.pro.ant.design/ 在本机 Chrome 首次访问和一次重载后均显示空白；网页读取也无正文，因此没有完成该预览内具体页面的目视核验。
- 使用官方仓库的 [defaultSettings.ts](https://github.com/ant-design/ant-design-pro/blob/master/config/defaultSettings.ts) 核对浅色导航、主色和流式内容等默认选择。
- 使用可访问的 [ProLayout 文档](https://pro-components.antdigital.dev/components/layout/) 核对导航、面包屑、页面标题、折叠与响应式骨架；使用 [ProTable 文档](https://pro-components.antdigital.dev/components/table/) 核对查询区、标题工具栏、状态展示和分页模式。
- 下表中的尺寸是本项目的工程选择，参照官方模式组织，没有声称来自不可见预览的精确测量。品牌、菜单、业务字段和记录保持 MamreTek CMDB 自身内容。

## 调整对比

| 区域       | 原先                                         | 本次调整                                                          |
| ---------- | -------------------------------------------- | ----------------------------------------------------------------- |
| 布局导航   | 深色侧栏、大品牌区、底部宣传语               | 白色顶栏与侧栏；当前项高亮；桌面收起/展开；手机抽屉导航           |
| 页面标题   | 英文装饰眉题、宣传式标题                     | 面包屑 + 20px 业务标题 + 简短业务说明                             |
| 查询与操作 | 查询控件直接混在表格卡片顶部，主要操作在页头 | 独立带标签查询区；表格标题/总数在左，新建/排序/刷新在右           |
| 资源列表   | 留白和装饰偏多，彩色状态标签                 | Ant Design 中等表格密度；普通行操作；状态点配合文字；右下分页     |
| 总览       | 渐变引导区、装饰图标、模型大卡片             | 真实数量统计、模型分布表、最近变更表；保留新建和导入入口          |
| 表单与详情 | 已有 Ant Design Form/Modal/Drawer/Tabs       | 保留字段、分组、校验和提交位置，跟随统一 tokens；没有改写业务流程 |
| 样式       | 自定义蓝、10px 圆角、较大标题                | 主色 #1677ff、6px 基础圆角、24px 桌面内容间距、标准字体层级       |
| 手机       | 抽屉导航与可滚动表格                         | 保留导航和表格内滚动，查询区单列、工具栏换行，页面本身无横向溢出  |

资源关系视图作为 CMDB 的业务视图保留；关系维护、配置项建档/修改/退役、CSV 校验导入、变更记录、模拟失败与重试均保持原业务语义。Mock 标识、无权限保护说明及刷新重置边界继续可见。

- `npm run check` 通过：格式、lint、strict 类型、34 项测试及构建。

- 已目视核对桌面资源清单、配置项表单和手机清单。截图由本地检查生成在 Git 忽略的 artifacts 目录：cmdb-pro-list-desktop.png、cmdb-pro-form-desktop.png、cis-mobile.png。

本轮为本地展示迭代，保留了此前尚未提交的局域网 HTTP UUID 兼容修复及其测试。没有覆盖无关改动，没有推送代码、更新远端 PR、合并或生产部署；PR #2 仍是 dc1e1f4 版本。当前本地预览在既有 5191 端口运行。

所有数据仍为内存 Mock，刷新重置；没有真实后端、持久化或新增权限保护。构建保留共享 UI/runtime chunk 体积提示（约 625 kB minified / 203 kB gzip）。

## 可配置资源迭代

继续沿用相同 tokens 与企业后台骨架：模型页面使用可展开字段表和模型关系规则页签；新建模型、字段及基数编辑使用 Modal + Form；字段确认前展示存量影响。导入保留步骤提示，补充模式选择、列映射和表格内逐字段差异。资源查询区补充保存视图、负责人和单属性等值条件。服务依赖树用于表达业务关系，沿用标准 Card/Tree/Link/Tag，限制三层与 200 节点并标识截断，没有增加装饰性大图。

参考官网本轮网页读取仍无可读正文，继续使用可访问的官方 ProTable 和 Form 文档；具体链接和参考范围见 product-references.md。未复制两项参考 CMDB 的代码或素材。
