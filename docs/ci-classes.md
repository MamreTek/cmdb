# CI Class 与字段类型

CI Class 与资源模型是同一个实体（API 仍使用 modelId）。已有主机、业务服务、数据库保留原标识和资源，作为根类；导航中的“全部 CI Class”仅用于浏览。

## 层级和继承

- 新建类时可选一个已有父类，最多6层。支持树形浏览、定位、选择和创建子类；父类建档后固定，不提供移动/删除、多继承或覆盖同名字段。
- 子类有效字段由根到叶依次组成，`originModelId` 标明声明类。继承字段在子类只读；类型、必填、默认值、唯一性等约束全部继承。引用目标为某类时允许其子类资源；退役引用保留规则不变。
- 唯一性作用于字段声明类及其完整子树，含退役资源；不是每个叶类分别唯一。关系规则按具体类匹配，不自动继承，避免无意扩大可关联范围。
- 父类追加字段先检查所有子类的同名冲突和全部相关资源。影响预览列出类、版本、资源数、默认回填和错误；有任一阻塞则整体不写入。成功后全部受影响类的 revision 增加；仅实际回填的CI增加revision与变更记录。
- 资源清单默认只查所选类；勾选“包含子类”后按子树查询，可保存此条件。CSV、表单和详情使用同一有效字段定义，固定CI.id/externalKey/modelId保持不变。

## 数据库风格字段

这里提供逻辑类型和Mock校验，不执行SQL或DDL；真实数据库的字符集、行大小、排序规则、索引和迁移仍需后续验证。原有text/number/boolean/date/enum/reference继续兼容。

| 类型           | 输入和约束                                                                                                                                                                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| varchar        | JSON字符串，首尾空白按现有契约移除；默认255个Unicode码点，可配置1–4096。超长拒绝，不截断；该原型上限不等于数据库最大长度。                                                                                                                           |
| integer        | JSON数字，有符号32位整数；可在-2147483648至2147483647内设置minValue/maxValue，小数、越界和JSON字符串均拒绝。CSV解析为数字后使用相同校验。                                                                                                            |
| timestamp      | 带显式Z或时区偏移的RFC3339子集，秒必填，最多3位毫秒；拒绝无时区、未知偏移-00:00、非法日历和闰秒，规范化为UTC字符串。兼容范围1970-01-01T00:00:01.000Z至2038-01-19T03:14:07.499Z。唯一性按规范化后的时间点检查；默认值是固定时间，不自动获取当前时间。 |
| long（待确认） | 用户尚未明确是64位长整数还是长文本；不启用歧义别名。确认后将分别命名，若为64位整数需通过十进制字符串传输，避免JavaScript精度损失。                                                                                                                   |

类型和范围参考 [MySQL整数](https://dev.mysql.com/doc/refman/8.4/en/integer-types.html)、[VARCHAR](https://dev.mysql.com/doc/refman/8.4/en/char.html)、[TIMESTAMP](https://dev.mysql.com/doc/refman/8.4/en/datetime.html) 与 [RFC3339](https://www.rfc-editor.org/rfc/rfc3339)。本原型不是上述数据库或标准的完整实现；特别是timestamp按明确的毫秒子集和MySQL兼容范围收敛。

## 类型调整预览

声明类字段的“预览迁移”可评估候选类型、长度、整数范围、必填/唯一/默认值；展示子树影响、合法规范化差异及阻塞行。仅可预览本类声明字段，子类不能改写继承字段。整数候选仅尝试解析严格十进制整数字符串，不截断小数；timestamp仅处理已有显式时区值，不猜测时区。

这是只读评估：不修改类、CI、关系、变更记录或导入令牌。没有应用迁移接口；不可逆类型调整需要另行明确确认。当前所有数据仍为内存Mock，刷新重置，未接入真实数据库或生产数据。
